## dna-comple
A simple python program that takes a DNA sequence as its input and prints out the reverse complementary strand
DNA helix consists of two strands that are anti-parallel and complementary to each other.
# PAIRING:
The nitrogenous bases Adenine pairs with Thymine through a double hydrogen bond and Cytosine pairs with Guanine with triple hydrogen bond, thus the complementarity between the base pairs adds to the stability of the DNA helix in storing the genetic information.
# HOW TO USE:
Enter the DNA sequence of your choice. The program is built to display the reverse complementary strand.
Additionally, the program also tells you if the strand is a palindrome(The sequence on both strands are the same; example:GAATTC)
